# Adaptive Learning — Phase 1: Skill Model + Capture — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Silently learn a per-user skill model (category ability + per-topic knowledge with hierarchical shrinkage) from every non-ranked answer, persisted to a new `user_skill_state` table. No player-facing behavior change yet.

**Architecture:** A pure-function knowledge-tracing core (`services/skill_model.py`) — online 1PL-IRT/Elo update for category ability `θ`, BKT update for per-topic `P(known)`, and shrinkage that blends a thin topic toward its category prior. A thin service (`services/skill_state.py`) applies one answer to a persisted `UserSkillState` row (per-user JSONB, mirroring `UserTasteProfile`). The apply is called best-effort from the existing signal chokepoint `services/taste_profile.py::record_answer_signal`, so every practice/quick/category/ranked answer already flowing through there updates skill state. Ranked selection/scoring is untouched.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy 2.x async, Alembic, pydantic-settings, pytest (rolled-back transaction per test), uv, ruff, mypy.

**Scope note:** Phase 1 only *writes* skill state (silent). Phase 2 (adaptive selection/scheduler) and Phase 3 (felt UI) are separate plans and are NOT in this document. Review scheduling (`review_due_at`) and mastery-level display buckets are deferred to those phases; Phase 1 captures `theta`, `p_known`, `attempts`, and `last_answered_at` only.

```python
BKT_P_TRANSIT: float = 0.12  # P(learn) applied after each observation
BKT_P_GUESS: float = 0.25  # 4-option MC guess floor
BKT_P_SLIP: float = 0.10  # P(slip): known but answered wrong
```

```python
"""Pure knowledge-tracing math for the adaptive-learning engine (Phase 1).

Two estimators, no DB, no I/O — every function is deterministic and unit-tested:

  * Category ability ``theta`` — an online 1PL-IRT / Elo estimate on a logit scale. Item difficulty
    ``b`` comes from the LLM ``difficulty_score``; the update size scales with the surprise
    (outcome - expected) and a learning rate that decays with attempts, so a settled ability is
    stable but still tracks real change.
  * Per-topic ``p_known`` — a Bayesian Knowledge Tracing posterior (guess/slip/transition).
  * ``effective_p_known`` — hierarchical shrinkage: a thin topic (few attempts) is blended toward
    the category-implied prior so sparse per-topic data can't swing wildly.
"""

from __future__ import annotations

import math

from app.core.constants import (
    BKT_P_GUESS,
    BKT_P_SLIP,
    BKT_P_TRANSIT,
    KT_DIFFICULTY_MAX,
    KT_DIFFICULTY_MIN,
    KT_K_BASE,
    KT_K_DECAY,
    KT_K_MIN,
    TOPIC_INDEPENDENCE_MIN,
)


def _clamp(x: float, lo: float, hi: float) -> float:
    return lo if x < lo else hi if x > hi else x


def difficulty_to_b(difficulty_score: float) -> float:
    """Map an LLM difficulty_score in [0, 1] to an item difficulty ``b`` on the ability scale."""
    d = _clamp(difficulty_score, 0.0, 1.0)
    return KT_DIFFICULTY_MIN + d * (KT_DIFFICULTY_MAX - KT_DIFFICULTY_MIN)


def expected_correct(theta: float, b: float) -> float:
    """1PL-IRT response function: probability an ability ``theta`` answers item ``b`` correctly."""
    return 1.0 / (1.0 + math.exp(-(theta - b)))


def update_theta(
    theta: float, attempts: int, difficulty_score: float, correct: bool
) -> tuple[float, int]:
    """Online ability update. Returns (new_theta, attempts + 1)."""
    b = difficulty_to_b(difficulty_score)
    p = expected_correct(theta, b)
    k = max(KT_K_MIN, KT_K_BASE / (1.0 + attempts / KT_K_DECAY))
    outcome = 1.0 if correct else 0.0
    return theta + k * (outcome - p), attempts + 1


def bkt_update(p_known: float, correct: bool) -> float:
    """BKT posterior + learning step. Returns the new P(known) in [0, 1]."""
    p = _clamp(p_known, 0.0, 1.0)
    if correct:
        num = p * (1.0 - BKT_P_SLIP)
        den = num + (1.0 - p) * BKT_P_GUESS
    else:
        num = p * BKT_P_SLIP
        den = num + (1.0 - p) * (1.0 - BKT_P_GUESS)
    posterior = num / den if den > 0.0 else p
    return _clamp(posterior + (1.0 - posterior) * BKT_P_TRANSIT, 0.0, 1.0)


def category_prior_known(theta: float) -> float:
    """The category-implied prior P(known) for a typical (average-difficulty) item."""
    return expected_correct(theta, 0.0)


def effective_p_known(bkt_p: float, category_prior: float, topic_attempts: int) -> float:
    """Shrinkage blend: thin topics lean on the category prior, sampled topics trust their BKT."""
    w = min(1.0, topic_attempts / TOPIC_INDEPENDENCE_MIN)
    return w * bkt_p + (1.0 - w) * category_prior
```

```python
"""Apply a single answer to a user's persisted skill state (Phase 1).

Loads the answered question's AI metadata (category, topics, difficulty), runs the pure
knowledge-tracing updates, and reassigns the JSONB maps on the (created-if-absent) UserSkillState
row. Called best-effort from record_answer_signal; a NULL/unclassified question is a no-op.
"""

from __future__ import annotations

import uuid

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.constants import BKT_P_L0, KT_THETA_INIT
from app.models import QuestionAIMetadata, UserSkillState
from app.services.skill_model import (
    bkt_update,
    category_prior_known,
    update_theta,
)


async def apply_answer_to_skill_state(
    session: AsyncSession,
    user_id: uuid.UUID,
    question_id: uuid.UUID | None,
    correct: bool,
) -> None:
    """Update (user)'s category ability + per-topic knowledge from one answered bank question."""
    if question_id is None:
        return
    meta = await session.scalar(
        select(QuestionAIMetadata).where(QuestionAIMetadata.question_id == question_id)
    )
    if meta is None or not meta.category:
        return  # unclassified → nothing reliable to learn from

    state = await session.scalar(
        select(UserSkillState).where(UserSkillState.user_id == user_id)
    )
    if state is None:
        state = UserSkillState(user_id=user_id, category_ability={}, topic_knowledge={})
        session.add(state)

    # --- category ability (reassign, never mutate the JSONB in place) ---
    ability = dict(state.category_ability)
    cur = ability.get(meta.category, {"theta": KT_THETA_INIT, "attempts": 0})
    theta, attempts = update_theta(
        float(cur["theta"]), int(cur["attempts"]), float(meta.difficulty_score or 0.5), correct
    )
    ability[meta.category] = {"theta": theta, "attempts": attempts}
    state.category_ability = ability

    # --- per-topic knowledge (BKT posterior; prior seeded from BKT_P_L0 for a new topic) ---
    knowledge = dict(state.topic_knowledge)
    for topic in meta.topic_tags or []:
        t = knowledge.get(topic, {"p_known": BKT_P_L0, "attempts": 0, "last_answered_at": None})
        knowledge[topic] = {
            "p_known": bkt_update(float(t["p_known"]), correct),
            "attempts": int(t["attempts"]) + 1,
            "last_answered_at": None,  # timestamp wired in Phase 2 (review scheduling)
        }
    state.topic_knowledge = knowledge

    await session.flush()
```

> `category_prior_known` is imported for parity with the reader side and Phase 2; if ruff flags it as unused in Phase 1, drop the import (the shrinkage read happens in Phase 2's selector, not here).
